# User Stories

## As a developer, I want to initialize the agent harness with a single line of code so that I can start building agents quickly.

## As a developer, I want to configure the LLM endpoint and API key via environment variables or a config file so that I can switch between providers easily.

## As a developer, I want to register tools (functions) that the agent can call so that it can interact with external systems.

## As a developer, I want the agent to automatically compress and summarize conversation history so that token usage stays low.

## As a developer, I want to see a token count and estimated cost after each agent run so that I can monitor expenses.

## As a developer, I want to enable self-reflection so the agent can critique its own answers and improve.

## As a developer, I want to chain multiple tool calls in a reasoning loop (ReAct style) so the agent can accomplish complex tasks.

## As a developer, I want to persist short-term memory across runs so the agent can recall recent context.

## As a developer, I want to plug in different memory backends (in-memory, SQLite, Redis) so I can scale as needed.

## As a developer, I want to run the agent in both synchronous and asynchronous modes so I can integrate with async applications.

## As a tester, I want unit tests for each core component (LLM wrapper, tool executor, memory, planner) so I can ensure reliability.

## As a DevOps engineer, I want Dockerfile and CI/CD pipeline templates so I can deploy the harness consistently.
